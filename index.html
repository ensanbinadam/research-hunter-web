النسخ الاحتياطي

احتفظ بتصنيفاتك ومسوداتك وجولة البحث، وانقلها إلى جهاز آخر.

نسخة Web كاملة

ملف JSON يشمل المكتبة، ومسودة المولّد، واختيارات البحث، وموضع الجولة الحالية.

تصنيفات قابلة للمشاركة

حدّد التصنيفات في صفحة المكتبة ثم صدّرها بصيغة المولّد والإضافة، أو اجمع عدة ملفات JSON.

آخر حفظ محلي سابق

نحتفظ بلقطة سابقة سليمة قبل الحفظ. يمكنك تنزيلها ومراجعتها قبل استعادتها.

خصوصيتك، ببساطة

لا حسابات ولا تحليلات زيارات ولا خطوط خارجية. تُعالج ملفاتك داخل المتصفح، وتُرسل عبارات الدفعة إلى X فقط عندما تفتح البحث.

الحفظ مرتبط بعنوان الموقع وهذا المتصفح. مسح بيانات المتصفح يمسح المكتبة المحلية؛ النسخة القابلة للتنزيل تحفظها خارج المتصفح.
