# الصياد الباحث Web | Research Hunter Web

الإصدار **1.1.5** — مولّد تصنيفات، ومكتبة قابلة للمراجعة، وبحث متعدد بالدفعات في X. يعمل بملفات HTML وCSS وJavaScript دون إضافة متصفح أو مفتاح API أو خادم خاص.

- [افتح الموقع](https://ensanbinadam.github.io/research-hunter-web/)
- [نزّل أحدث شيفرة المشروع](https://github.com/ensanbinadam/research-hunter-web/archive/refs/heads/main.zip)

## ما الجديد؟

- حفظ إصدارات المصطلحات الرقمية مثل `3.5 turbo`، وعزل تلف الأجزاء الثانوية في التخزين عن المكتبة مع حفظ أصل البيانات والتنبيه.
- استعادة ونسخ احتياطي يعملان مع المرشحات غير الصالحة مؤقتًا، وحفظ الحالة الحالية أولًا عند ضيق المساحة دون حذف اللقطة القديمة.
- نصوص أوضح وتباين أقوى، وحساب أخف لخطة البحث أثناء الكتابة، وسياسة تمنع الاتصالات والمصادر الخارجية غير المطلوبة.

- جدول بجميع الجولات: رقم الجولة ورابط فتح مستقل، مع إظهار المحتوى اختياريًا. تجهيز الجدول والسابق والتالي لا يفتحون X تلقائيًا.

- إصلاح فتح نتائج X مباشرة، وإزالة محاولة إعادة توجيه نافذة معزولة التي قد يمنعها المتصفح.

- برومبت يحدد الموضوع والنطاق والفترة، ويطلب مصطلحات متخصصة دون حشو، ويشترط إرفاق شاهد عند ادعاء التحقق من حساب أو مصطلح.
- قراءة إجابة JSON منظمة مع الشواهد والحسابات والاستبعادات المقترحة، مع استمرار دعم الإجابات النصية القديمة بالأقسام الأربعة.
- مراجعة كل مصطلح: مقترح، أو ملائم بعد مراجعتك، أو مستبعد؛ مع رابط شاهد وتاريخ وملاحظة.
- تنبيهات لصياغة الهاشتاق، والعبارات الواسعة، والروابط أو أوامر البحث الموضوعة داخل العبارات، وحدود الأطوال.
- قوالب محفوظة لكل تصنيف: حتى 10 حسابات، تواريخ، لغة، استبعادات، عبارات مطلوبة، مطابقة دقيقة أو كلمات بأي ترتيب، واستبعاد الردود وإعادة النشر.
- تصدير دفعات البحث إلى CSV أو قائمة روابط، وسجل محلي لمراجعة فائدة عينات النتائج يدويًا.
- صيغة مكتبة Web تحفظ المراجعات والقوالب، إلى جانب ملف التصنيفات المتوافق مع الإضافة والنسخة الاحتياطية الكاملة.

## ابدأ بالبحث أو بالمولّد

تبدأ المكتبة بالتصنيفات الخمسة الأصلية وعباراتها الـ127 من إضافة الصياد الباحث 1.3.0. لا تُقرأ بيانات الإضافة الشخصية تلقائيًا؛ صدّرها منها واستوردها في المكتبة.

للبحث: اختر التصنيفات والمرشحات، ثم اضغط «تجهيز جولات البحث». تظهر أرقام الجولات وروابط «فتح» في جدول داخل الصياد دون فتح نتائج تلقائيًا. استخدم Ctrl مع النقر أو زر الفأرة الأوسط لفتح الجولة في الخلفية في Chrome على سطح المكتب؛ النقر العادي قد ينقلك إلى التبويب الجديد بحسب المتصفح. يمكن إظهار عبارات الجولات بخيار مستقل، وتُحفظ الجولة المحددة محليًا. السابق والتالي يغيّران التحديد فقط، ويوجد رابط لفتح الجولة المحددة. لا يوجد فتح جماعي أو تلقائي.

لإنشاء تصنيفات جديدة:

1. اكتب الموضوع والتفاصيل والنطاق والفترة في المولّد.
2. ولّد البرومبت وانسخه إلى أداة الذكاء التي تختارها. البحث عن مصادر فعلية يتوقف على قدرة تلك الأداة؛ المولّد لا يستدعي نموذجًا بنفسه.
3. ألصق إجابة JSON كاملة في «نص الإجابة»، ثم وزعها على المجموعات.
4. راجع الحسابات والاستبعادات المقترحة واختر ما تريد استخدامه. لا تُفعّل تلقائيًا.
5. اضغط «إضافة ومراجعة المصطلحات» لتسجيل قراراتك، أو أضف المجموعات للمكتبة ثم راجعها من زر «مراجعة».

الملف [samples/research-draft-demo.json](samples/research-draft-demo.json) مثال تمثيلي يُلصق في حقل الإجابة؛ ليس ملف مكتبة يُستورد، وحساباته وشواهده أمثلة تدريبية لا توصيات فعلية.

## المراجعة والشواهد

يفحص البرنامج بنية القائمة وصياغتها. لا يستطيع تحديد صحة المعلومات أو صلة جميع نتائج X بالموضوع، ولا يمنح درجة جودة آلية.

من نافذة مراجعة التصنيف يمكنك تصفية المصطلحات إلى غير المراجعة، أو الملائمة، أو المستبعدة، أو الوسوم، أو ذات التنبيهات. افتح بحث المصطلح أو شاهدَه، ثم سجّل قرارك وملاحظتك واضغط «حفظ المراجعة» قبل الانتقال إلى غيره.

**المستبعد يبقى محفوظًا في المكتبة وملاحظاتها، لكنه لا يدخل البحث أو ملف التصدير للإضافة.** ويمكن إعادته بتغيير حالته. تظل شواهد الذكاء وحساباته مقترحة حتى تراجعها؛ وجود رابط أو شارة توثيق لا يثبت موثوقية المحتوى.

## قوالب البحث

من بطاقة التصنيف اضغط «قالب بحث»، أو حدد تصنيفًا واحدًا في مساحة البحث واحفظ إعداداته الحالية. لتحميل قالب استخدم القائمة أعلى المرشحات.

- العبارات البديلة مترابطة بـ `OR`.
- عند تحديد حسابات متعددة، يكفي ظهور المنشور من أحدها.
- جميع العبارات في حقل «عبارات يجب وجودها» شروط إضافية مطلوبة.
- مطابقة الكلمات بأي ترتيب تطلب كلمات كل عبارة معًا، مع إبقاء العبارات المختلفة بدائل.
- يوم النهاية غير مشمول.
- عند جمع عدة تصنيفات تُطبّق إعدادات مساحة البحث الحالية على الجولة كلها. لا تخلط الأداة قوالب متعارضة تلقائيًا.

لا تضع `from:` أو `since:` أو روابط داخل حاوية العبارات؛ استخدم حقول القالب. تبقى فاعلية مرشحات نتائج البحث تحت سيطرة X.

## قياس فائدة النتائج

بعد بدء الجولة افتح «تسجيل فائدة عينة راجعتها». أدخل عدد المنشورات التي فحصتها والملائم منها، واسم التجربة وملاحظات الفترة. يُحفظ الاستعلام مع العينة ويمكن تصدير السجل إلى CSV.

النسبة تخص **العينة التي راجعتها أنت**؛ ليست نسبة صحة جميع النتائج، ولا قياسًا للشمول أو الرواج. للمقارنة بين قائمتين استخدم الموضوع والمرشحات والفترة وحجم العينة وطريقة الاختيار نفسها. لا يتضمن هذا الإصدار ادعاءً مثبتًا بنسبة تحسن في نتائج X أو جودة نموذج خارجي.

## التصدير والنسخ الاحتياطي

حدّد بعض التصنيفات أو الكل بمربعات «اختيار للتصدير». عند عدم الاختيار تظهر رسالة ولا يُنشأ ملف فارغ. التحديد مستقل عن تحديد البحث ويُحفظ محليًا.

| الملف | ما يحتفظ به |
| --- | --- |
| «تصدير المحدد» | تصنيفات الإضافة v2 بعباراتها الفعّالة فقط؛ دون المراجعات والقوالب |
| «تصدير المحدد مع المراجعات والقوالب» | مكتبة Web v1، بما فيها العبارات المستبعدة وقراراتك وشواهدك |
| «نسخة Web كاملة» | المكتبة كلها، والمسودة وشواهدها، والاختيارات، والجولة، وسجل مراجعات النتائج |
| CSV أو روابط الدفعات | استعلامات الاختيار الحالي وروابطها؛ ملفات للتنزيل وليست مكتبة للاستيراد |

استيراد المكتبات يدمجها بعد معاينة دون استبدال المكتبة. عند تشابه الاسم واللغة يحتفظ الدمج بالمراجعات والقالب الموجودين، ويضيف المصطلحات الجديدة وشواهدها؛ أو يمكنك الاحتفاظ بالتصنيفين بأسماء مختلفة. استعادة نسخة Web كاملة تستبدل الحالة بعد تأكيد، مع تجهيز نسخة قبل الاستعادة للتنزيل.

تدعم القراءة `research-hunter-categories` و`prompt-hunter-categories` الإصدار 2، و`research-hunter-web-library` و`research-hunter-web-backup` الإصدار 1. صيغة إجابة المولّد `research-hunter-draft` الإصدار 1.

## الحدود والحفظ

المكتبة حتى 50 تصنيفًا للتوافق مع الإضافة، وحتى 2000 عبارة للتصنيف و500 حرف للعبارة داخليًا. التصدير للإضافة يشترط ألا تتجاوز العبارة 120 حرفًا؛ النسخ الغنية تحفظها دون اختصار. الاسم حتى 65 حرفًا والوصف حتى 160 والرمز حتى 4. ملف الاستيراد حتى 8 ميغابايت، وحتى 20 ملفًا في عملية الدمج، وسجل مراجعات النتائج حتى 100 عينة.

حد دفعة البحث المحافظ 380 حرفًا شاملًا المرشحات و3500 حرف للرابط المشفر. إذا كانت عبارة مفردة مع المرشحات أطول من ذلك يظهر خطأ دون إسقاطها.

يظل مفتاح التخزين المحلي السابق مستخدمًا، وتُضاف الحقول الجديدة بقيم آمنة دون مسح المكتبة القديمة. عند وجود مرشح غير صحيح مؤقتًا يُحفظ باقي العمل مع آخر إعدادات بحث سليمة. توجد لقطة محلية سابقة، لكن النسخة القابلة للتنزيل هي وسيلة النقل والاستعادة خارج المتصفح. الحفظ مرتبط بأصل الموقع والمتصفح والجهاز. عند تلف جولة أو جزء من المسودة أو العينات محليًا نحافظ على التصنيفات السليمة، ونصفّر الجزء التالف وحده مع تنبيه، بعد حفظ الأصل في سجل استعادة محلي. إذا تعذر تأمين الأصل يتوقف الحفظ وتبقى البيانات قابلة للتنزيل. لا يُطبّق هذا التسامح على ملفات الاستيراد. تتضمن النسخة الكاملة سجل الاستعادة إن وجد، والمرشحات المؤقتة غير الصالحة في حقل `recoveryData` للمراجعة؛ لا تعيد الاستعادة تطبيقها تلقائيًا. عند تعذر تحديث اللقطة السابقة يُعرض تنبيه، ولا تُحذف اللقطة القديمة. يرجى تنزيل نسخة خارج المتصفح دوريًا.

## نتائج X والخصوصية

تُفتح النتائج في X دون iframe أو API أو جمع للمنشورات. روابط جدول الجولات روابط عادية تستجيب للنقر العادي وCtrl أو زر الفأرة الأوسط دون اعتراض طريقة فتح المتصفح. تجهيز الجولات والسابق والتالي لا يفتحون نتائج؛ لا تُعاد محاولة توجيه تبويب X معزول عن الموقع. إزالة التكرار تخص عبارات البحث؛ لا تجمع الأداة المنشورات ولا تزيل تكرارها بين الدفعات. روابط الفتح ظاهرة في الجدول ولا تعتمد على فتح نوافذ برمجيًا.

الملفات والمسودات والمراجعات تُعالج محليًا. لا تُفتح الشواهد أو صفحات الحسابات ولا تُرسل الاستعلامات إلى X إلا بفعل المستخدم. اقرأ [PRIVACY.md](PRIVACY.md).

## التشغيل والنشر والاختبارات

افتح `index.html` في متصفح حديث أو استخدم الخادم المحلي؛ استضافة HTTPS أو الخادم المحلي موصى بهما لاستقرار التخزين والنسخ للحافظة. لا توجد حزم تشغيل خارجية:

```sh
npm test
npm run build
npm run dev
```

تحتاج الاختبارات Node.js 20 أو أحدث. البناء يجهّز `dist/`، وملفات الجذر جاهزة للنشر المباشر. يستخدم الموقع روابط أصول نسبية مع إصدار لتقليل خلط الملفات القديمة والجديدة بعد التحديث.

راجع [PUBLISHING.md](PUBLISHING.md)، و[TEST-REPORT.md](TEST-REPORT.md)، و[CHANGELOG.md](CHANGELOG.md)، و[SOURCE-NOTES.md](SOURCE-NOTES.md). لم يُضف ترخيص مفتوح جديد إلى المشروع، ولم تتغير الإضافة أو المولّد المنشوران منفصلًا.
