# الصياد الباحث Web | Research Hunter Web

نسخة ويب مستقلة تجمع مولّد التصنيفات ومكتبتها والبحث المتعدد في منصة X. تعمل بملفات HTML وCSS وJavaScript، دون تثبيت إضافة أو حساب خاص بالموقع أو خادم أو مفتاح API.

## ابدأ الآن

افتح `index.html` في متصفح حديث، أو شغّل `npm run dev` وافتح `http://127.0.0.1:4173`. الاستضافة عبر HTTPS أو خادم محلي هي الطريقة الموصى بها لاستقرار التخزين والنسخ إلى الحافظة. سلوك التخزين عند فتح ملفات `file://` يختلف بين المتصفحات.

تبدأ المكتبة بالتصنيفات الخمسة الأصلية وعباراتها الـ127 من إضافة الصياد الباحث 1.3.0. هذه بداية قابلة للتعديل، وليست قراءةً لبياناتك الشخصية المحفوظة في الإضافة. لن تنتقل تصنيفاتك المخصصة تلقائيًا: صدّرها من الإضافة واستورد ملف JSON هنا.

## ما الذي تتضمنه النسخة؟

- **مساحة البحث:** اختيار عدة تصنيفات، جمع العبارات وإزالة تكرارها، إضافة عبارات مؤقتة، وتقسيمها إلى دفعات مع السابق والتالي.
- **نطاق البحث:** الأحدث أو الأبرز أو الحسابات أو الوسائط، اللغة، الحساب، التاريخ والاستبعادات. تبقى فاعلية المرشحات خاضعة لسلوك X.
- **المكتبة:** إضافة وتحرير وحذف، بحث محلي، اختيار التصنيفات المراد تصديرها بمربعات اختيار، تحديد الكل أو إلغاء التحديد، واستيراد ملفات متعددة مع معاينة الدمج.
- **المولّد:** بناء برومبت بالعربية أو الإنجليزية أو كليهما، توزيع إجابة الذكاء على أربع مجموعات قابلة للتحرير، ثم إضافتها مباشرة إلى المكتبة والبحث. المولّد لا يستدعي نموذجًا بنفسه.
- **الحفظ:** تخزين محلي للمكتبة والمسودة والاختيارات والجولة، لقطة سابقة، ونسخة Web كاملة قابلة للتنزيل والاستعادة.
- **واجهة عربية متجاوبة:** اتجاه RTL، تنقل بلوحة المفاتيح، تسميات للحقول، ومكونات محلية دون خطوط أو مكتبات خارجية.

## البحث وتبويب X

1. اختر التصنيفات وعدّل نطاق البحث.
2. راجع عدد العبارات الفريدة والدفعات والتكرارات المستبعدة.
3. اضغط «بدء البحث في X» لفتح أول دفعة.
4. عُد إلى الصياد واضغط «التالي» أو «السابق». موضع الجولة محفوظ ويمكن إعادة فتح دفعتها الحالية.

يستخدم الموقع اسم نافذة ثابتًا ومرجعًا للتبويب لمحاولة إعادة استخدامه. **إعادة استخدام تبويب X ليست مضمونة**: قد يفصل X أو المتصفح الاتصال بين الصفحتين بسياسة عزل النوافذ، وقد لوحظ فتح تبويب جديد أثناء اختبار Chrome الفعلي. كذلك تضيع الإشارة إلى التبويب عند إعادة تحميل الموقع. لا يستطيع موقع مستقل فرض إعادة الاستخدام كما تفعل إضافة تملك صلاحية التبويبات. توجد وصلة يدوية عند حظر النوافذ المنبثقة.

لا توجد إطارات `iframe`، أو واجهة X API، أو قراءة آلية للنتائج. إزالة التكرار تخص **عبارات البحث**؛ لا تُزال المنشورات المتكررة بين دفعات X. وقد يتطلب عرض النتائج تسجيل الدخول إلى X.

تُربط العبارات بـ `OR` وتوضع العبارات العادية بين علامتَي تنصيص. حد الدفعة المحافظ **380 حرفًا شاملًا المرشحات**، مع حد 3500 حرف للرابط المشفّر وحد قابل للاختيار لعدد العبارات. إذا تجاوزت عبارة مفردة الحد يظهر خطأ؛ لا تسقط عبارات دون تنبيه.

## صيغ الملفات والحدود

لتصدير بعض التصنيفات، افتح المكتبة واختر مربع «اختيار للتصدير» في كل تصنيف تريده، ثم اضغط «تصدير المحدد». زر «تحديد الكل» يشمل المكتبة كلها حتى عند استخدام مرشح البحث. إذا لم تحدد أي تصنيف تظهر رسالة «حدّد بعض التصنيفات أو الكل لتصدير المكتبة»، ولا يُنشأ ملف فارغ. يُحفظ اختيار التصدير محليًا بصورة مستقلة عن اختيار البحث. «نسخة Web كاملة» تحفظ المكتبة بأكملها دائمًا.

| الاستخدام | الصيغة |
| --- | --- |
| تبادل التصنيفات مع المولّد والإضافة | `research-hunter-categories`، الإصدار `2` |
| استيراد ملفات قديمة | `prompt-hunter-categories`، الإصدار `2` |
| نسخة Web الكاملة | `research-hunter-web-backup`، الإصدار `1` |

المكتبة تدعم 50 تصنيفًا. حجم الملف المستورد حتى 8 ميغابايت، وحتى 20 ملفًا في عملية دمج واحدة. يُرفض الملف غير الصحيح، ولا يطبّق الدمج إلا بعد معاينة سليمة والضغط على «إضافة إلى المكتبة».

تدعم النسخة 2000 عبارة لكل تصنيف و500 حرف للعبارة داخليًا. لتوافق التصدير مع الإضافة، يجب ألا تتجاوز العبارة **120 حرفًا**؛ إذا تجاوزت ذلك يُمنع تصدير التصنيفات مع إرشاد واضح، وتبقى النسخة الكاملة تحفظ النص دون اختصار. اسم التصنيف حتى 65 حرفًا والوصف حتى 160 والرمز حتى 4. لغة التصنيف `ar` أو `en` أو `mixed`.

استيراد التصنيفات يضيف إلى المكتبة. استعادة نسخة Web الكاملة تستبدلها بعد تأكيد، مع تجهيز نسخة من الحالة الحالية للتنزيل قبل الاستبدال. احتفظ بالملف المنزّل فعلًا؛ اللقطة المحلية السابقة ليست بديلًا عن نسخة خارج المتصفح.

## النشر والاختبارات

خطوات النشر على مستودع مستقل باسم `research-hunter-web` في [PUBLISHING.md](PUBLISHING.md). لا يلزم تثبيت حزم لتشغيل الموقع أو اختباره:

```sh
npm test
npm run build
npm run dev
```

الاختبارات تستخدم Node.js 20 أو أحدث. أمر البناء ينسخ ملفات الموقع إلى `dist/`؛ ملفات الجذر جاهزة أيضًا للنشر مباشرة. سير GitHub Actions المرفق يشغّل الاختبارات والبناء، بينما نشر Pages الافتراضي يتم من `main / (root)` وفق الدليل.

راجع [TEST-REPORT.md](TEST-REPORT.md) للتغطية وحدود الفحص، و[PRIVACY.md](PRIVACY.md) للخصوصية، و[SOURCE-NOTES.md](SOURCE-NOTES.md) لمصادر الشيفرة.

هذه نسخة مستقلة. لم تُعدّل ملفات الإضافة المثبّتة أو مستودع المولّد المنشور. لم يُضَف ترخيص مفتوح جديد إلى شيفرة المشروع؛ اختيار الترخيص لصاحبه.
